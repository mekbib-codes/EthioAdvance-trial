# 🌐 EthioAdvance – Smart Tutoring Made Simple

- EthioAdvance is a modern web platform built to simplify and improve tutoring services in Ethiopia. The system connects parents, students, and tutors through a user-friendly online portal, offering transparency, efficiency, and accountability in the tutoring process.


- Parents can create accounts, register multiple children, track tutor session times, check timely child status, and handle all payments online using Chapa. Tutors are registered and assigned to a child by an admin, They are only assigned after a first free session with child and an approval from the parent. They also use the system to provide brief daily summary about sessions and monthly reports. After each session, parents receive a notification and can approve or decline the session before billing is processed at a standard rate of 400 ETB/hour.

# ✨ Key Features
- Parent dashboard with child registration and session monitoring
- Session approval system for parents
- Online payment integration with Chapa
- Tutor dashboard with child monitoring, proivding session summaries & reports
- Clean and responsive UI (built with Django templates + HTMX)
- Role-based access: Parents & Tutors access different pages

**Whether you're a busy parent, a dedicated tutor, or an admin managing operations, EthioAdvance makes tutoring simple, organized, and fully online.**
